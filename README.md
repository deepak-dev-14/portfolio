# Deepak Kumar | Portfolio

A responsive personal portfolio for Deepak Kumar, an MCA student and aspiring web developer based in Patna, India. It highlights selected projects, education, skills, and contact details.

## Features

- Responsive layout with a collapsible mobile navigation menu
- About, education, projects, skills, resume, and contact sections
- Scroll-triggered reveals and subtle parallax effects, with reduced-motion preferences respected
- Project previews with links to live demos and source repositories
- Downloadable PDF resume and a print-friendly resume view
- Contact form that prepares a message in the visitor's default email app

## Built With

- HTML
- CSS
- Vanilla JavaScript
- DM Sans and Caveat fonts from Google Fonts

## Run Locally

No package installation or build step is required. Clone the repository and open `portfolio.html` in a browser, or serve the folder with a local development server such as the VS Code Live Server extension.

```bash
git clone https://github.com/deepak-dev-14/portfolio.git
cd portfolio
```

## Deployment

The page entry point is `portfolio.html`. GitHub Pages looks for `index.html` at the published folder's root, so rename `portfolio.html` to `index.html` (and update any links that refer to it) before publishing with the standard GitHub Pages root-folder setup.
